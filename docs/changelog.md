## [v4-archive] — 2026-11-02

The v4 era: BTK 5-plane kernel, LOOM 5-tab IA, 12 invariants, 30-table schema, 8-phase plan. Real Kotlin/Compose code shipped (~70 files). Reached P2 (rituals & reminders). Killed 2026-11-04 because enterprise architecture for one student, vocabulary of a knowledge worker, complexity prevented shipping. Code preserved in git history.

## [v5-archive] — 2026-11-03

The v5 era: "The Living Bloom" — garden metaphor, 5 petals (Bloom/Garden/Soil/Keeper/Voice). Web prototype built (Next.js, ~12 components). Worked end-to-end. Killed 2026-11-04 because garden was a skin not a soul, no discipline pressure, not unique enough. Web prototype code wiped from local sandbox (not pushed).

## [v6-fire] — 2026-11-04

The v6 era: "The Fire" — discipline-first, two-tier (Lite/Full), system-level Watcher, on-device Forge. Vision doc locked. Repo restructured. P0 Spark about to begin.
